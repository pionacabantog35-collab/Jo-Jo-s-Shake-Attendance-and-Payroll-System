**Jo-Jo's Shake Attendance and Payroll System**

The Jo-Jo's Shake Attendance and Payroll System is a desktop-based system designed to help manage employee attendance and payroll transactions for Jo-Jo's Shake. The system helps simplify the recording of employee time-in/time-out, attendance monitoring, and payroll computation.

**Features**

-Employee information management

-Employee attendance tracking

-Time-in and time-out recording

-Automatic calculation of working hours

-Payroll computation

-Salary and deduction management

-Net pay calculation

-Payroll transaction records

-Database storage for employee and payroll information

**Technologies Used**

-C#

-Windows Forms

-Visual Studio 2022

-MySQL

-XAMPP

-phpMyAdmin

**System Overview**

The system was developed as an academic project to demonstrate the use of programming, database management, and desktop application development.

It combines attendance monitoring and payroll processing into one system, allowing employee records and payroll-related information to be organized and managed more efficiently.

**Database**

The system uses MySQL as its database and phpMyAdmin for database management through XAMPP.

**The database stores information such as:**

-Employee records

-Attendance records

-Work hours

-Payroll information

-Salary and deductions

-Net pay

**Purpose of the Project**

This project was created to apply concepts learned in programming and database management, particularly in developing a functional desktop application with database connectivity.

It also provided hands-on experience in:

-C# Windows Forms development

-CRUD operations

-MySQL database integration

-Payroll computation

-Attendance tracking

-User interface design
